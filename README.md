# Free Rip

A free pack-opening toy that runs inside a post on X. No wallet, no sign-up, nothing on-chain.

Fan project. Card images are loaded from tcgdex.net and pokemontcg.io; card data comes from the open pokemon-tcg-data set files. Not affiliated with Nintendo, Creatures, Game Freak or The Pokemon Company.

Rebuild the card list: `node tools/build-cards.js <folder with the set json files>`.
